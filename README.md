# Smart Credit Book – Digital Kadai Kanakku

## 1. Project Overview
Smart Credit Book is a digital credit management system designed
for small retail and grocery shops. It replaces manual notebook
records with a digital system for managing customer credit,
purchases, payments, and pending balances.

## 2. Problem Statement
Small shop owners often use notebooks to record customer purchases
and credit balances. Finding old entries, calculating pending dues,
and tracking payments manually can be time-consuming and may cause errors.

## 3. Objectives
- Maintain customer details digitally.
- Record purchases and payments.
- Calculate pending credit balances.
- Track customer payment history.
- Display sales and payment summaries.
- Provide AI-based credit reminders and suggestions.

## 6. System Architecture
Users interact with the web interface built using HTML, CSS,
and JavaScript. Firebase Realtime Database stores customer,
purchase, and payment-related data. Firebase Hosting publishes
the application online.

## 7. Database Structure
The application uses Firebase Realtime Database.

Main data sections:
- customers
- purchases
- settings

Purchase records include customer information, items,
total amount, amount paid, due amount, and date.

## 8. Testing
The application was checked for customer entry, purchase recording,
payment collection, credit balance updates, dashboard summaries,
reports, and settings.

Further testing will cover invalid inputs, database errors,
and additional edge cases.
